# 🧠 LLM From Scratch — Medical AI

Building a GPT-style language model from scratch and extending it into a Medical AI Assistant capable of analyzing blood reports and explaining medical insights.

---

# 🚀 Goals

- Learn how LLMs work internally
- Build transformer architecture from scratch
- Train a mini GPT model
- Fine-tune medical domain models
- Build blood report analyzer
- Implement RAG pipeline
- Deploy scalable AI system

---

# 🛠️ Tech Stack

## Core
- Python
- PyTorch
- NumPy

## LLM / NLP
- Hugging Face Transformers
- Tokenizers
- sentence-transformers

## Medical AI
- Pandas
- FAISS
- LangChain / LangGraph

## Backend
- FastAPI

## Deployment
- Docker
- AWS / GCP
